## 🎨 Image Implementation

### Code Location

Images are mapped in two files:

1. **Equipment List Page** (`pages/equipment/index.js`)
2. **Equipment Detail Page** (`pages/equipment/[slug].js`)

### Image Map Structure

```javascript
const imageMap = {
  'cnc-lathe-vtu': 'https://www.focus-cnc.com/...',
  'fdm-3d-printer': 'https://zbotic.in/...',
  'a100-ai-server': 'https://www.nvidia.com/...',
  // ... etc
}
```

### Fallback Behavior

Items without images display a gradient background:
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

### Load Times
- External images load from their respective CDNs
- Lazy loading reduces initial page load
- Images only load when scrolled into view

### Caching
- Browser caches external images
- Reduces bandwidth on repeat visits
- Faster subsequent page loads

### Optimization Tips
1. **Use WebP format** when possible
2. **Compress images** before uploading
3. **Use CDN** for faster delivery
4. **Implement progressive loading**
5. **Add blur placeholders**

## 🐛 Troubleshooting

### Image Not Loading

**Possible Causes:**
- External URL blocked or changed
- CORS restrictions
- Slow network connection
- Image deleted from source

**Solutions:**
1. Check browser console for errors
2. Verify URL is still accessible
3. Try opening URL directly in browser
4. Update to new URL if needed
5. Fallback gradient will display

### Image Quality Issues

**Solutions:**
- Find higher resolution source
- Use manufacturer's official images
- Consider hosting images locally
- Optimize image compression

### Slow Loading

**Solutions:**
- Enable lazy loading (already implemented)
- Use smaller image sizes
- Implement image CDN
- Add loading placeholders
